JM-Rec — step by step

A walk-through of JM-Rec with real screenshots. The numbers in brackets refer to the matching image; the order mirrors the flow you follow in the app.

1. Welcome

(01) The start screen

JM-Rec remembers the last organ you worked on. When you start a new session it asks whether you want to continue with that organ or set up a new one.

  • Continue with this organ — opens the main screen in the exact state you last left it: same storage folder, same stops, same progress.
  • Set up a new organ — starts the ten-step wizard described below.

2. The wizard — ten steps

Ten short steps set up the whole structure: where the recordings go, which builder and church it is, what the manuals and stops look like. Any step can be revisited with the arrow at the bottom left.

(02) Step 1 — Storage location

The folder where all recordings are kept. Pick an empty folder on a drive with enough space — a typical set runs to several gigabytes. JM-Rec creates a sub-folder per organ there, so you can record multiple organs side by side.

(03) Step 2 — Organ builder

The name of the organ builder (for example Van Vulpen, Flentrop, Reil). JM-Rec keeps this as metadata on the recordings, so you see at a glance which organ you're playing in JM-Orgue.

(04) Step 3 — Place

The town or village where the organ sits (for example Putten). Together with the church name this makes up the label the organ shows under in your library.

(05) Step 4 — Church name

The name of the building (Old Church, Great Church, …). It's written into the recordings as info text and appears on the organ's library card in JM-Orgue.

(06) Step 5 — Year built

The year the organ was built, optional. Leave the field blank if it's unknown.

(07) Step 6 — Audio settings

Choose your recording device (microphone or “what you hear” loopback), channel count, sample rate and bit depth. By default JM-Rec records in mono at 48 000 Hz / 16-bit as MP3; this works for most pipe organs.

(08) Step 7 — MIDI

Which MIDI device plays the organ? Pick the MIDI input your console or keyboard uses. If you work with the “what you hear” loopback against a virtual organ, you can select a virtual MIDI port (loopMIDI) and let JM-Rec drive the notes itself.

(09) Step 8 — Manuals

Which manuals does the organ have, and which MIDI channel does each use? A typical two-manual organ has Great, Swell and Pedal. Each manual gets its own channel so JM-Rec sends the notes to the right one when it walks through automatically.

(10) Step 9 — Stops per manual

The heart of the setup. Per manual you list the stops, their pitch (8′, 4′, 2′, a mixed “4 st”…) and the MIDI note range they speak over. Use middle C = MIDI 36 as a memory aid. A bass/treble split stop (Trumpet 8 B/D) gets the “bass/disc” tick.

(11) Step 10 — Overview

The last step shows the full picture: number of manuals, number of stops, total recordings to make, expected disk usage. If it looks right, finish the wizard; if you want to tweak something, step back with Previous.

3. Recording

(12) The main screen

After the wizard you land on the main screen. The note that's up next is shown large (C2), with the file name it will be saved under (036-c.mp3) below it. The three buttons are:

  • Record — starts the capture and, in a “smart” setup, moves on to the next note automatically.
  • Pause — stops between two notes; handy when a disturbance comes along.
  • Stop — closes the current recording and returns to “Ready”.

At the bottom you see all stops per manual (Great, Swell, Pedal) with their progress. The colour legend — still to record (red), incomplete (yellow), to be checked (purple), good (green) — tells you where you stand at a glance.

(13) Stop complete

As soon as the last pipe of a stop is in, a dialog comes up. You pick:

  • Check now — opens the verification screen for this stop right away.
  • Approved — marks the stop done and moves on to the next.
  • Later — keeps the stop at “to be checked” so you can listen through it later.

4. Verifying

(14) Verification screen

Via the Check button at the top — or the dialog from step 13 — you reach the verification screen. JM-Rec shows per tone whether the recording is valid: leading silence, clipping, a tail that cuts off too early — every issue is flagged with a colour and a symbol. Re-recording a single note is one click away.

(15) Loop detection

Pipe organ tones last long; for samplers a “loop” is set so the tone can keep sounding without the recording having to be endlessly long. JM-Rec proposes one or more loop points per tone, shows them in the waveform and plays them back on demand. One click confirms the suggestion or picks a different spot.

5. Wireless control

(16) QR Remote

The QR Remote button shows a QR code with the network address (for example http://192.168.1.10:5570). Scan it with your phone or tablet and the remote opens in the browser. You drive Record, Pause and Stop and see the current note from the organ bench — no apps to install.

No wifi? Turn on the Mobile hotspot in Windows (button Open hotspot settings at the bottom), connect your phone to that network and pick the hotspot network from the drop-down here.

6. The result in JM-Orgue

Opening the recordings

Once the recordings are in, start JM-Orgue, open the library and click Open organ…. Point it to the storage folder you chose in step 1 and the organ turns up in the library with all the manuals, stops and couplers you set in the wizard. From there, it plays like any other sample set.
